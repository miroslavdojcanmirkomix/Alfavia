ALFAVIA – záhlavie s logom materskej spoločnosti OVB

Do hlavného priečinka GitHub repozitára nahrajte celý obsah tohto ZIP-u.
Zmenené sú všetky HTML stránky a styles.css; pridaný je súbor ovb-allfinanz-slovensko.png.
Logo ALFAVIA a OVB sú vizuálne oddelené. OVB je označené ako materská spoločnosť podľa zadania.
Kliknutie na logo OVB otvorí oficiálnu stránku https://www.ovb.sk/ v novej karte.
Na mobile sa značka OVB zobrazí ako menší štítok medzi logom ALFAVIA a tlačidlom menu.
Pred komerčným zverejnením si overte oprávnenie používať logo a označenie vzťahu medzi spoločnosťami.
